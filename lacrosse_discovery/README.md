# LaCrosse Discovery add-on

Scans USB serial ports for a JeeLink running the `LaCrosseITPlusReader`
sketch, listens for LaCrosse/Technoline sensor packets, and generates a
ready-to-paste `sensor: - platform: lacrosse` block for Home Assistant's
built-in [`lacrosse` integration](https://www.home-assistant.io/integrations/lacrosse/).

See [DOCS.md](DOCS.md) for full usage instructions (also shown in the
add-on's "Documentation" tab in Home Assistant).
